Используется для [[Способы защиты данных|защиты данных]] при передаче. Способен найти и устранить одно искажение.

Код Хэмминга с $m$ проверочных бит состоит из $2^m-1$ бит. Где $m$ - количество контрольных бит. Контрольный бит $p_i$ имеет номер $2^i$, остальные биты - информационные.
#### Построение
1. В номере каждого контрольного бита ровно одна единица.
2. Вычисляем значение через [[Полином Жегалкина]]: $p_i = d_a\oplus d_b\oplus\dots$ где номера $a, b,\dots$ в двоичной форме имеют единицу там же, где она расположена в двоичной записи $i$.
3. Расставляем биты по правилу.
#### Чтение
1. Проходимся по контрольным битам
2. Для каждого вычисляем $s_i = p_i\oplus d_a\oplus d_b\oplus\dots$, годе номера $a,b,\dots$ - в двоичной форме имеют единицу там же, где она стоит в двоичной форме номера $i$.
3. Вычислаем синдром: $syn = \sum s_i * i$ 
4. Если $syn\neq0$, значит в бите номер $syn$ произошло искажение, и его нужно инвертировать.
5. Выделить информационные биты
