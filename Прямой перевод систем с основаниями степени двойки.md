#info
Это частный случай [[Перевод чисел между системами счисления|общего перевода чисел между системами счисления]] — применим только когда оба основания являются степенями двойки.

Если требуется перевести число из одной системы счисления в другую, при этом обе системы имеют основание $2^n$, то совершить перевод можно минуя десятичную систему.

### Перевод из двоичной в $2^k$-ричную систему
1. Убедиться, что количество бит делится на k
2. Если нет добавить незначащие нули
3. Разбить код на группы по $k$ бит
4. Конвертировать каждую группу в $k$-ричную цифру
5. Склеить цифры в одно число.

Пример:
1. `1110101101` в восьмеричную
2. Добавим нули: `001110101101`
3. Выделим группы: `(001)(110)(101)(101)`
4. Переведём цифры: `(1)(6)(5)(5)`
5. Результат: `1655`

### Перевод из $2^k$-ричной в двоичную
1. Переводим каждую цифру в $k$-битное двоичное число
2. Склеиваем их в один код и убираем незначащие нули

Пример для 16-ричной системы:
`3A7 -> (0011)(1010)(0111) -> 001110100111 -> 1110100111`
