[[Система булевых функций]] называется полной тогда и только тогда, когда она не принадлежит целиком ни одному из пяти базовых замкнутых классов:
1. $T_0$ - функции, сохраняющие $0$. $f(0, 0, \dots) = 0$
2. $T_1$ - функции, сохраняющие $1$. $f(1, 1, \dots) = 1$
3. $S$ - самодвойственные функции. Если инвертировать все аргументы, значение функции также инвертируется.
4. $M$ - монотонные функции. Если увеличить значения некоторых аргументов, то значение функции не уменьшится.
5. $L$ - линейные функции. Их [[Полином Жегалкина]] не содержит конъюнкций.
