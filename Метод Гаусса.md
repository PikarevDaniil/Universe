# Для невырожденной квадратной матрицы
1. Привести матрицу коэффициентов к [[Треугольная матрица|треугольному виду]]. Над матрицей свободных членов выполняют те же преобразования.
2. В нижней строке поделить свободный член на ненулевой коэффициент
3. Полученное число — последнее решение системы
4. Подняться на строку выше
5. Из свободного члена вычесть произведение известных корней на соответствующие им коэффициенты
6. Результат поделить на коэффициент при последнем неизвестном корне
7. Повторять, пока не найдутся все корни
### Программная реализация
```Python
def find_roots(m: list, free: list) -> list:
    n = len(free)
    res = [0] * n
    for i in range(n-1, -1, -1):
        for j in range(n):

            s = sum([res[j] * m[i][j] for j in range(n) if i != j])

        res[i] = (free[i] - s) / m[i][i]

    return res
```
Где `m` — _треугольная_ матрица, `free` — соответствующий ей вектор свободных членов.

# В других случаях
1. Соединить матрицу коэффициентов ($A$) и свободных членов ($B$) в одну $A|B$
2. Привести эту матрицу к [[Ступенчатая матрица|ступенчатому виду]], используя [[Элементарные преобразования матриц]]
3. Вычеркнуть нулевые строки, если есть.
4. Сравнить [[Ранг матрицы|ранги]] матриц $A$ и $A|B$. Если они не совпадают, то есть возникает уравнение $0 = b$, то решений нет. Матрица _несовместна_
5. Сравнить количество строк (уравнений) и столбцов (переменных):
	1. Если строк меньше, то решений бесконечно много. Система _неопределена_
	2. Если столбцов больше или столько же, то решение только одно. Система _определена_. См. **квадратные матрицы**.
6. Выбрать базис — квадратную невырожденную подматрицу.
7. Выделить переменные, образующие её. Остальные переменные принять за буквы.
8. Двигаясь снизу вверх, выражать неизвестные переменные через числа и буквы.
9. Ответ записать в виде суммы матриц:
	1. Матрица-столбец с числами
	2. Матрицы-столбцы с коэффициентами букв, умноженные на сами буквы.
10. Таким образом, мы записали формулу для вычисления матриц решения системы.
