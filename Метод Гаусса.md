## Описание алгоритма
1. Привести матрицу к коэффициентов к [[Треугольная матрица|треугольному виду]]. Над матрицей свободных членов следует выполнять те же операции, что и над матрицей коэффициентов
2. В нижней строке поделить свободный член на ненулевой коэффициент
3. Полученное число - последнее решение системы
4. Подняться на строку выше
5. Из своободного члена вычесть произведение известных корней на соответствуйщие им коэффициенты
6. Результат поделить на коэффициент при последнем неизвестном корне
7. Повторять пока не найдутся все корни
## Программная реализация
```Python
def find_roots(m: list, free: list) -> list:
    n = len(free)
    res = [0] * n
    for i in range(n-1, -1, -1):
        for j in range(n):

            s = sum([res[j] * m[i][j] for j in range(n) if i != j])

        res[i] = (free[i] - s) / m[i][i]

    return res
```
Где `m` - _треугольная_ матрица, `free` - соответсвуйщий ей вектор свободных членов.
