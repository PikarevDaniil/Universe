#math #linal 
Треугольной называют квадратную матрицу, в которой элементы, что ниже главной диагонали, равны нулю.

Любую невырожденную квадратную матрицу можно преобразовать в треугольную. Для этого используется вычитание из одной строки другой, умноженной на число.

Программная реализация конвертации матрицы в треугольную:
```Python
def to_triangle(m: list, free: list) -> list:
    n = len(free)
    top = 0
    for _ in range(n-1):
        for row in range(top+1, n):
            if m[top][top] == 0:
                return []

            k = m[row][top] / m[top][top]
            a = [m[row][i] - m[top][i]*k for i in range(n)]
            m[row] = a
            free[row] -= free[top] * k

        top += 1

    det = 1
    for i in range(n):
        det *= m[i][i]

    return m if det else []
```
Где `m` - квадратная матрица, `free` - вектор свободных членов системы линейных уравнений.
