## Перевод из n-ричной в десятеричную
$n=\sum{a_i*n^{n-i-1}}$ 

Кодом:
```Python
def to_dec(num: str, a: int) -> int:
	if not (2 <= a <= len(alpha) + 10):
		raise ValueError(f'Невалидное основание системы счисления: {a}')
	res = 0
	n = len(num)
	for i in range(n):
		d = num[::-1][i]
		if not d.isdigit():
			d = alpha.index(d) + 10

	if int(d) + 1 > a: 
	        raise ValueError(f'Слишком большая цифра: {d}')

		res += int(d) * a**i
	
	return res
```

## Перевод из десятичной в n-ричную
Тут есть два способа
### Через деление
1. Делем число на основание
2. Остаток записываем в результат
3. Повторяем, пока число натуральное
4. Переворачиваем результат

Программой:
```Python
def from_dec(num: int, a: int) -> str:
	if not (2 <= a <= len(alpha) + 10):
		raise ValueError(f'Невалидное основание системы счисления: {a}')
		
	res = ''
	if not num: return '0'
	while num >= 1:
		d = num % a
			if d >= 10:
				d = alpha[d - 10]
			else:
				d = str(d)

		res += d
		num //= a

	return res[::-1]
```

### Через разряды
1. Находим ближайшее $n^i<a$ где $a$ - данное число
2. Перебираем $i$ до нуля в обратном порядке
3. Записываем в результат $a / n^i$, округлённое вниз
4. Вместо исходного числа записываем остаток от $a / n^i$
5. В результате получаем строку

Программой:
```Python
def from_dec(num int, a: int) -> str:
	if not (2 <= a <= len(alpha) + 10):
		raise ValueError(f'Невалидное основание системы счисления: {a}')
	if not num: return '0'
	res = ''

	for g in range(int(log(num, a)), -1, -1):
		d = num // a**g
		if d >= 10: d = alpha[d - 10]
		else: d = str(d)

		res += d
		num %= a**g

	return res
```
