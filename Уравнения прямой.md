# На плоскости
## 1. Основные объекты

- **Направляющий вектор** $\vec s = (l, m)$ — ненулевой вектор, параллельный прямой.
- **Нормальный вектор** $\vec n = (A, B)$ — ненулевой вектор, перпендикулярный прямой.
- Связь: $\vec n \perp \vec s$, т. е. $A l + B m = 0$. Если $\vec n = (A, B)$, то можно взять $\vec s = (-B, A)$.
- **Угловой коэффициент** $k = \operatorname{tg}\alpha$, где $\alpha$ — угол наклона прямой к оси $Ox$. Для $\vec s = (l, m)$: $k = m/l$.

## 2. Виды уравнений прямой

| Вид                     | Уравнение                                                                     | Что задаёт                                      |
| ----------------------- | ----------------------------------------------------------------------------- | ----------------------------------------------- |
| Общее                   | $Ax + By + C = 0$                                                             | нормаль $\vec n = (A, B)$                       |
| Через точку и нормаль   | $A(x - x_0) + B(y - y_0) = 0$                                                 | $M_0(x_0, y_0)$, $\vec n = (A, B)$              |
| Каноническое            | $\dfrac{x - x_0}{l} = \dfrac{y - y_0}{m}$                                     | $M_0(x_0, y_0)$, $\vec s = (l, m)$              |
| Параметрическое         | $\begin{cases} x = x_0 + l t \\ y = y_0 + m t \end{cases}$, $t \in \mathbb R$ | то же, $t$ — параметр                           |
| С угловым коэффициентом | $y = kx + b$                                                                  | $k$ — наклон, $b$ — ордината пересечения с $Oy$ |
| Через точку и $k$       | $y - y_0 = k(x - x_0)$                                                        | $M_0(x_0, y_0)$, $k$                            |
| Через две точки         | $\dfrac{x - x_1}{x_2 - x_1} = \dfrac{y - y_1}{y_2 - y_1}$                     | $M_1(x_1, y_1)$, $M_2(x_2, y_2)$                |
| В отрезках              | $\dfrac{x}{a} + \dfrac{y}{b} = 1$                                             | отрезки $a$, $b$ на осях ($a, b \ne 0$)         |
| Нормальное (Гессе)      | $x\cos\varphi + y\sin\varphi - p = 0$                                         | $p \ge 0$ — расстояние от начала координат      |
> [!note]
> Чтобы перейти от общего вида к нормальному, нужно умножить уравнение на _нормирующий множитель_
> $$
> \mu = \frac{sgn\ C}{\sqrt{A^2+B^2}}
> $$
> где $sgn\ x$ - [[Основные функции|Сигнум]]

# В пространстве
Пусть $M_0(x_0, y_0, z_0)$ — точка на прямой, $\vec s = (l, m, n)$ — направляющий вектор.

- **Каноническое:** $\dfrac{x - x_0}{l} = \dfrac{y - y_0}{m} = \dfrac{z - z_0}{n}$
- **Параметрическое:** $$\begin{cases}
x = x_0 + lt,\\
y = y_0 + mt,\\ 
z = z_0 + nt
\end{cases}$$
- **Через две точки**: $$\frac{x-x_1}{x_2-x_1}=\frac{y-y_1}{y_2-y_1}=\frac{z-z_1}{z_2-z_1}$$Где $M_1(x_1\ y_1\ z_1)\in\ell$ и $M_2(x_2\ y_2\ z_2)\in\ell$
